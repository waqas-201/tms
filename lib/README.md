## Invariants
- Validates coupon scope, expiration, minimum subtotal, and usage limits in [coupons.ts:validateCoupon]
- Requires verified customer email address in [auth.ts:emailVerified]
- Requires user session context in [auth.ts:session]
- Enforces staff separation from patient actions in [rbac-base.ts:isStaffRole]
- Enforces available stock sufficiency before reservation in [catalog.ts:getAvailableStock]
- Requires authenticated user session with roles [staff roles] in [rbac.ts:requireRole]
- Enforces cryptographic token or staff/owner access verification in [invoice-token.ts:verifyInvoiceToken]
- Enforces available stock sufficiency before reservation in [inventory.ts:getAvailableStock]
